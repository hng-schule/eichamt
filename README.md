# Das Eichamt von Maßlingen

Kostenloses Rätselspiel (Escape Room) für Mathematik Klasse 5: Rechnen mit Größen (Geld, Gewicht, Länge, Zeit), passend zum Kerncurriculum Niedersachsen. Gedacht für iPads im Querformat (Safari), funktioniert aber in jedem aktuellen Browser.

- Keine Anmeldung, keine Datensammlung, keine Werbung.
- Drei Stufen: Entdecker, Forscher, Profi. Die Stufe lässt sich im Spiel jederzeit wechseln.

Die ganze Anwendung steckt in `index.html`. Lizenzen siehe `LIZENZEN.txt`.
